ICE — installable app files

Upload ALL of these files (not the folder) to a GitHub repository, then turn on GitHub Pages:
  index.html, manifest.webmanifest, sw.js, icon-192.png, icon-512.png, icon-maskable-512.png

Then open https://YOUR-USERNAME.github.io/REPO-NAME/ in Chrome on your phone,
tap the three-dot menu, and choose "Install app" (or "Add to home screen" > Install).

To update later: upload the new index.html over the old one. The app picks it up
the next time you open it with internet.
